# Game sound credits

All files in this folder are original arrangements built from **Interface Sounds** by Kenney
(https://www.kenney.nl), released under **CC0 1.0** (public domain, no attribution required; credit given anyway).
Source clips were fetched from the CC0 mirror https://github.com/Calinou/kenney-interface-sounds
(pluck_001, glass_001, tick_001, drop_002, confirmation_001). Audio was only downloaded and processed; nothing was executed.

Processing: clips were pitch-shifted (resampled) to scale notes, sequenced into short melodies/loops with a small
script, soft-clipped, normalised and encoded as mono 32 kHz MP3 with ffmpeg. No third-party music, no brand assets.

| File | What it is |
| --- | --- |
| lobby-loop.mp3 | 16 s seamless loop: C-Am-F-G arpeggio on pluck, glass melody, soft kick and ticks |
| question-loop.mp3 | 10 s quiet loop for question time (host can mute) |
| join, countdown, go | player joins; 3-2-1 beep; start chime |
| tick, last5 | clock tick; last-five-seconds double tick |
| correct, wrong, streak, timeup | answer feedback |
| reveal, winner | leaderboard sting; winner fanfare |
| box, double, steal, bomb | mystery box pick and twists |
